게임 데이터 이사

저장 데이터는 주소마다 따로 보관돼요. 그래서 새 주소로 옮기면 진행 상황이 비어 보입니다. 예전 주소에서 코드를 만들어, 새 주소에서 붙여넣으면 모든 게임의 기록이 그대로 따라옵니다.

1단계 · 예전 주소에서

이 기기의 저장 데이터 내보내기

아래 버튼을 누르면 이 주소에 저장된 모든 게임 기록이 코드 하나로 만들어집니다.

코드가 길어요. 복사하기 버튼을 쓰고, 메모 앱이나 카톡 나에게 보내기로 옮기면 편합니다.
2단계 · 새 주소에서

저장 데이터 불러오기

1단계에서 만든 코드를 붙여넣고 불러오기를 누르세요.

이미 새 주소에서 게임을 하셨다면, 불러오기가 그 기록을 덮어씁니다. 진행하기 전에 한 번 더 확인해요.
